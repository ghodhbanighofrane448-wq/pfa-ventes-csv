# pfa-ventes-csv projet  d’analyse automatique de fichiers CSV en Python
Fichiers du projet:
ventes.csv : fichier csv cree par python d'apres un tableau de données 
resultats_final.csv : fichier de sortie généré automatiquement par  Python après le  traitement des données
ventes_dynamique.py : programme  principal qui lit le fichier CSV , traite les données et effectue les calculs.
centes.py:version non dynamique du projet
